# 功能文档索引

P1 阶段新增了四个能力。每份文档都按"**是什么 / 为什么 / 怎么用 / 怎么验证 / 面试怎么说**"写，方便你自己看懂，也方便讲给别人。

| 文档 | 功能 | 一句话 |
|---|---|---|
| [01-查询改写](01-查询改写.md) | 查询改写 + 指代消解 | 把用户口语/代词问题改写成检索友好的 2-3 个版本 |
| [02-反馈](02-反馈.md) | 点赞 / 点踩 | 用户标"有用/没用"，落到 jsonl 作为 bad case 池 |
| [03-多会话](03-多会话.md) | 对话历史列表 | 同一浏览器可以有多段对话，切换/新建/删除 |
| [04-LLM-as-judge](04-LLM-as-judge.md) | 模型当裁判 | 用 LLM 给答案的忠实度、相关性打分 |

## 这些功能之间的关系

```
用户提问
   │
   ├─ 多会话：这段对话属于哪个 conv_id（03）
   │
   ├─ 查询改写：把问题改写成 2-3 个检索版本（01）
   │      └─ 指代消解：把"它"换成"选课系统"（01 里的一部分）
   │
   ├─ 检索 + rerank + 生成（原有）
   │
   ├─ 反馈：用户点 👍/👎（02）
   │
   └─ LLM-as-judge：离线评测时，用模型给答案打分（04）
```

## 怎么自己验证

```bash
# 1. 启动 Web
python web_demo.py

# 2. 浏览器打开 http://127.0.0.1:8000
#    - 页头「对话」→ 多会话（03）
#    - 问一个问题 → 答案下方 👍/👎（02）
#    - 追问"它什么时候..." → 看是否理解了指代（01）

# 3. 离线评测（需要 .env 里有 key）
python src/eval_judge.py --limit 5      # LLM-as-judge（04）
python src/eval_retrieval.py --split dev
```

## 想关掉某个功能

都在 `src/config.py` 里：

| 开关 | 默认 | 关掉后 |
|---|---|---|
| `QUERY_REWRITE` | `True` | 只用一个查询（旧行为） |
| `QUERY_REWRITE_MAX` | 3 | 最多生成几个查询 |

也可以不改代码，用环境变量：`QUERY_REWRITE=0 python web_demo.py`。
